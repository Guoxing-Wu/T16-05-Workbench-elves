# Author's Workbench User Stories

### Epic 1: Project Creation and Navigation

#### US1 Create a Writing Project

> As a user, I want to create a writing project with a target word count and average chapter length, so that the application has the information required to generate a projected chapter plan.

#### US2: View the Project Overview

> As a user, I want to view the current project’s planning settings and selected story structure in one overview, so that I can understand the project’s current configuration before continuing my planning work.

#### US3: Update Project Planning Settings

> As a user, I want to update the target word count and average chapter length after creating a project, so that the project settings can reflect changes to my writing goals.

#### US4: Navigate Between Core Project Areas

> As a user, I want to move between the project setup, story structure, projected chapter plan and notes while remaining in the same project, so that I can complete different planning activities without losing my current project context.



### Epic 2: Story Structure Templates and Automatic Chapter Mapping

#### US5: Select a Story Structure Template

> As a user, I want to select either a system-provided story structure template or my custom template, so that I can plan my manuscript by using the suitable story structure.

#### US6: Calculate the Projected Number of Chapters

> As a user, I want the application to calculate the projected number of chapters from my target word count and average chapter length, so that I can understand the expected size of my manuscript before planning individual chapters.

#### US7: Map Act Boundaries to Projected Chapters

> As a user, I want the application to calculate where each act begins and ends within the projected chapter plan, so that I can see how the selected story structure divides my manuscript.

#### US8: Map Story Beats to Projected Chapters

> As a user, I want the application to convert each story beat’s percentage position into a projected chapter position, so that I can see approximately where each important structural moment should occur in my manuscript.

#### US9: Recalculate the Projected Plan

> As a user, I want the projected chapter count, act boundaries and story-beat positions to be recalculated when I change the target word count or average chapter length, so that the plan remains consistent with my latest project settings.

#### US10: Create and Save a Custom Story Structure

> As a user, I want to create and save a custom story structure containing named acts and story beats at defined percentage positions, so that I can reuse my own planning method in future writing projects.
>
> I want to be able to:
>
> a) Give the custom structure a name;
> b) Create and organise acts;
> c) Add, edit, delete and reorder story beats;
> d) Set a percentage position for each story beat;
> e) Save the structure for later use.

#### US11: Manually Adjust the Generated Plan

> As a user, I want to manually adjust the projected chapter position of an act boundary or story beat after the plan has been generated, so that I can adapt the selected structure to the specific needs of my manuscript.



### Epic 3: Character Profiles and Management

#### US12: Create a Character

> As a user, I want to create a character with a name and basic profile information, so that I can identify and track that character throughout my story plan.

#### US13: View All Project Characters

> As a user, I want to view all characters saved in the current project, so that I can quickly select the character I want to inspect or update.

#### US14: View a Character Profile

> As a user, I want to view a character’s profile, including their recorded details and available links to story content, so that I can understand the character’s information in one place.

#### US15: Edit Character Information

> As a user, I want to edit a character’s recorded information, so that the character profile remains accurate when my story plan changes.

#### US16: Delete a Character

> As a user, I want to remove a character I no longer need from the project, so that obsolete character information does not remain in my story plan.

#### US17: Find and Organise Characters

> As a user, I want to search for characters by name and sort the character list, so that I can find a character efficiently when the project contains many characters.

#### US18: Record Additional and Custom Character Details

> As a user, I want to record additional details and custom fields in a character profile, so that I can store character information that is important to my particular story.

#### US19: Add a Character Image

> As a user, I want to add an optional reference image to a character profile, so that I can recognise the character visually.



### Epic 4：Character Age Tracking

#### US20: Record a Character’s Date of Birth

> As a user, I want to record a character’s date of birth, so that the application has the information required to calculate the character’s age at dated story events.

#### US21: Calculate a Character’s Age at an Event

> As a user, I want the application to calculate a character’s age from their date of birth and the date of a linked story event, so that I can check how old the character is when that event occurs.

#### US22: View Character Ages Across the Story

> As a user, I want to view a character’s calculated age at their dated events and milestones in chronological order, so that I can follow the character’s age progression throughout the story.

#### US23: Record Approximate Birth Information

> As a user, I want to record an approximate birth year or age range when an exact date of birth is unknown, so that I can still document uncertain character age information without presenting it as exact.



### Epic 5: Visual Chapter Plan and Notes

#### US24: View the Visual Chapter Plan

> As a user, I want to view projected chapters, acts and story beats together in a visual plan, so that I can understand how the selected story structure maps onto my manuscript.

#### US25: Open an Item from the Visual Plan

> As a user, I want to select a chapter, act or story beat in the visual plan and open its available details, so that I can inspect or update the selected item without searching elsewhere.

#### US26: Add Notes to a Chapter

> As a user, I want to add and edit notes or a summary for each projected chapter, so that I can record what I plan to write in that chapter.

#### US27: Add Notes to a Story Beat

> As a user, I want to add and edit notes for a story beat, so that I can record how that structural moment will be represented in my manuscript.

#### US28: Zoom the Visual Plan

> As a user, I want to zoom in and out of the visual plan, so that I can examine individual chapters or view the complete manuscript structure.



### Epic 6: Character Locations, Events and Milestones

#### US29: Record a Character’s Location

> As a user, I want to record a character’s location at a dated event, scene or story moment, so that I can track where the character is during the story.

#### US30: Record a Character’s Location Period

> As a user, I want to record the period during which a character remains at a location, so that I can represent their location over time rather than only at individual events.

#### US31: View and Correct Location History

> As a user, I want to view a character’s location records in chronological order and correct inaccurate records, so that I can maintain an accurate history of the character’s movements.
>
> a) View location records in chronological order;
> b) Edit an incorrect location record;
> c) Delete an unnecessary location record.

#### US32: Create a Story Event or Milestone

> As a user, I want to create a story event or character milestone with its core details, so that I can record an important development in the story.

#### US33: View and Manage a Story Event

> As a user, I want to view, edit and remove a story event, so that the event information remains accurate when my story plan changes.
>
> a) View event details;
> b) Edit event details;
> c) Delete an obsolete event after confirmation.

#### US34: Link Characters to an Event

> As a user, I want to link one or more characters to a story event, so that I can record who participates in or is affected by that event.

#### US35: Link an Event to the Story Structure

> As a user, I want to link an event to an act, chapter or story beat, so that I can see where the event appears in the planned manuscript.

#### US36: View a Character’s Story Journey

> As a user, I want to view all events and milestones linked to a selected character in chronological order, so that I can review the character’s journey throughout the story.

#### US37: Categorise Events

> As a user, I want to assign a category to an event, so that I can distinguish between different types of story developments and milestones.

#### US38: Record a Character’s Role in an Event

> As a user, I want to record each linked character’s role in an event, so that I can understand how each character participates in or is affected by it.

#### US39: Record Character Relationships

> As a user, I want to record relationships between characters and how those relationships change, so that I can follow their development throughout the story.

### Epic 7: Chronological Timeline and Continuity

#### US40: View a Chronological Story Timeline

> As a user, I want to view dated story events and character milestones in chronological order, so that I can understand the sequence in which events occur in the story world.

#### US41: Compare Story Time and Manuscript Order

> As a user, I want to compare the chronological order of events with the chapters in which they are presented, so that I can understand differences between story time and manuscript order.

#### US42: View Character Ages and Locations on the Timeline

> As a user, I want to view each linked character’s calculated age and recorded location at an event, so that I can review the character’s situation at that point in the story.

#### US43: Filter Timeline Information

> As a user, I want to filter the timeline by character, event category or chapter, so that I can focus on information relevant to my current planning task.

#### US44: Open Related Content from the Timeline

> As a user, I want to select an item on the timeline and open its details, so that I can inspect or update it without searching elsewhere.

#### US45: Reposition an Event on the Timeline

> As a user, I want to reposition an event on the timeline, so that I can efficiently adjust its chronological position in the story.

#### US46: Identify Possible Continuity Problems

> As a user, I want the application to identify possible age, date-order and location conflicts, so that I can review potential continuity problems in my story plan.



### Epic 8: Saving, Data Safety and Project Portability

#### US47: Save Project Changes

> As a user, I want my project settings, story structure, chapter plan and notes to be saved, so that I do not lose my planning work.

#### US48: Reopen a Saved Project

> As a user, I want to reopen a saved project with its planning information restored, so that I can continue working from where I stopped.

#### US49: Display the Save Status

> As a user, I want to see whether my latest changes have been saved, so that I know whether my work is safe.

#### US50: Warn About Unsaved Changes

> As a user, I want to be warned before leaving when changes have not been saved, so that I can avoid losing my work.

#### US51: Back Up and Restore a Project

> As a user, I want to export and import a complete project backup, so that I can recover my work or manually move it to another device.



### Epic 9: Export and Cross-platform Access

#### US52: Export the Story Plan to Microsoft Word

> As a user, I want to export my chapter plan, story structure and notes as a document that Microsoft Word can open, so that I can review or continue developing the plan outside the application.

#### US53: Export the Story Plan for Scrivener

> As a user, I want to export my story plan in a format that Scrivener can import, so that I can transfer the planned manuscript structure into my existing writing workflow.

#### US54: Use the Web Application Across Supported Platforms

> As a user, I want to access and edit my projects through supported web browsers on macOS, Windows and iOS or iPadOS, so that I can use the application without being limited to one operating system.



### Epic 10: Application Preferences and Deferred Extensions

#### US55: Adjust Application Preferences

> As a user, I want to adjust basic display preferences such as date format, so that the application better matches the way I organise my story information.

#### US56: Add a Project Image or Book Cover

> As a user, I want to add an optional image or book cover to a project, so that I can recognise the project visually.

#### US57: Create an Author Wiki Page

> As a user, I want to publish an author wiki page, so that I can share information about myself and my books.
