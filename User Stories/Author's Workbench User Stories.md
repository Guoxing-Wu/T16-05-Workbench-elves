# Author's Workbench User Stories

### Epic 1: Project Navigation and Story Structure Preview

#### US1 Switch Between Project Views

> As a user, I want to switch between the main project views, including story structure, characters, chapters, events and timeline, so that I can work on different parts of my writing project efficiently.

#### US2 Sidebar Navigation

> As a user, I want a consistent sidebar containing links to the main project views, Profile and Settings, so that I can understand where each function is located and navigate through the application easily.

#### US3 Collapse and Expand the Sidebar

> As a user, I want to collapse and expand the sidebar, so that I can create more screen space for planning and editing while keeping navigation available when needed.

#### US4 Return to the Project Overview

> As a user, I want to return to the Project Overview from any main page, so that I can quickly review the overall state of my project and choose what to work on next.

#### US5 Preview the Story Structure

> As a user, I want to preview my acts, chapters, scenes and plot points in a structured overview, so that I can understand how the different parts of my story are organised at a glance.

#### US6 Zoom the Structure Preview

> As a user, I want to zoom in and out of the story structure preview, so that I can switch between viewing the complete manuscript structure and examining individual story elements.

#### US7 Open Content from the Structure Preview

> As a user, I want to select a chapter, scene or plot point in the structure preview and open its related content, so that I can move directly from the overall plan to the part of the story I want to review or edit.





### Epic 2: Story Structure, Plot Points and Word Count

#### US8 Set a Total Word Count Target

> As a user, I want to set a target total word count for each writing project, so that I can plan the expected length of the complete manuscript.

#### US9 Organise Acts, Chapters and Scenes

> As a user, I want to create and organise acts, chapters and scenes in a hierarchical structure, so that I can divide my manuscript into clearly arranged sections.

#### US10 Allocate the Total Word Count

> As a user, I want to distribute the project’s target word count across its acts, chapters and scenes, so that I can plan how much of the manuscript should be allocated to each part of the story.

#### US11 Adjust Chapter and Scene Word Targets

> As a user, I want to change the target word count of an act, chapter or scene, so that I can rebalance the manuscript when the story structure or planned chapter lengths change.

#### US12 Manage Plot Points

> As a user, I want to manage plot points within acts, chapters and scenes, so that I can keep my plot plan aligned with the developing manuscript.
>
> I want to be able to:
>
> a) Create a new plot point;
>
> b) Edit an existing plot point;
>
> c) Delete a plot point that is no longer needed;
>
> d) Reorder plot points;
>
> e) Move a plot point between acts, chapters or scenes.

#### US13 View Story Structure Statistics

> As a user, I want to see the number of acts, chapters, scenes and plot points in my project, so that I can understand the current size and complexity of my story structure.

#### US14 Compare Planned and Actual Word Counts

> As a user, I want to compare planned and actual word counts for the complete project and its individual sections, so that I can see whether my manuscript is progressing according to its word count plan.

#### US15 Automatically Update Project Statistics

> As a user, I want project statistics to update when I change the story structure or manuscript content, so that the Project Overview reflects the latest state of my work.

#### US16 View the Last Edited Time

> As a user, I want to see when a project was last edited, so that I can identify my most recently updated writing project and understand when I last worked on it.





### Epic 3: Character Management

#### US17 Create a Character

> As a user, I want to create a character with a name and save the character to my project, so that I can track that character throughout the story.

#### US18 View All Project Characters

> As a user, I want to view a list of all characters saved in a project, so that I can quickly find the character I want to inspect or edit.

#### US19 View a Character Profile

> As a user, I want to view a character’s personal details and linked story information in one profile, so that I can understand the character without searching through different parts of the project.

#### US20 Edit Character Information

> As a user, I want to edit a character’s personal and story-related information, so that the character profile remains accurate when my story plan changes.

#### US21 Delete a Character

> As a user, I want to delete a character I no longer need, so that unnecessary character information does not remain in my project.

#### US22 Find and Organise Characters

> As a user, I want to find and organise characters in a large project, so that I can quickly locate the character profile I need.
>
> I want to be able to:
>
> a) Search for a character by name;
>
> b) Sort characters by name or creation time;
>
> c) Filter characters by available profile information or completion status.

#### US23 Record Additional Character Details

> As a user, I want to record additional personal and background information about a character, so that I can develop a richer and more useful character profile.

#### US24 Add Custom Character Fields

> As a user, I want to add custom fields to a character profile, so that I can record character information that is important to my particular story but is not covered by the standard fields.

#### US25 Add a Character Image

> As a user, I want to assign an avatar or reference image to a character, so that I can recognise the character visually in character lists and profiles.

#### US26 Track Character Profile Completion

> As a user, I want to see which important character information is missing and whether a profile is complete, so that I know which characters still require further development.





### Epic 4: Character Age Tracking

#### US27 Record a Character’s Date of Birth

> As a user, I want to record a character’s date of birth, so that the character’s age can be calculated at different points in the story.

#### US28 Calculate Age at an Event

> As a user, I want the system to calculate a character’s age using the character’s date of birth and the date of a linked event, so that I can check how old the character is when that event occurs.

#### US29 View Age Across Events and Milestones

> As a user, I want to see a character’s age at important events and milestones, so that I can follow the character’s age progression and identify possible continuity mistakes.

#### US30 Record an Approximate Age or Birth Date

> As a user, I want to record an approximate age or birth date when exact information is unknown, so that I can still plan the character’s age without entering details that have not been decided.





### Epic 5: Character Location Tracking

#### US31 Record a Character’s Location

> As a user, I want to record where a character is located during a particular event, scene or story date, so that I can track the character’s location throughout the story.

#### US32 Record a Character’s Location Period

> As a user, I want to record the period during which a character stays at a location, so that I can represent where the character is over time rather than only during individual events.

#### US33 View Character Location History

> As a user, I want to view a character’s locations in chronological order together with their related dates and events, so that I can understand how the character moves between places during the story.

#### US34 Manage Character Location Records

> As a user, I want to correct character location records, so that the location history remains accurate when my story plan changes.
>
> I want to be able to:
>
> a) Edit an existing location record;
>
> b) Delete an incorrect or unnecessary location record.

#### US35 Identify Conflicting Locations

> As a user, I want the system to identify when a character appears to be in conflicting locations at the same story time, so that I can review and correct possible location continuity errors.





### Epic 6: Events, Milestones and Character Relationships

#### US36 Create a Story Event

> As a user, I want to create an event while working with the story structure or timeline, so that I can record an important story development in the relevant context.

#### US37 Categorise an Event

> As a user, I want to assign a category to an event, so that I can distinguish between different types of story developments and character milestones.

#### US38 Record Core Event Details

> As a user, I want to record the essential details of a story event, so that I can understand what happens, when it happens and where it takes place.

#### US39 Link Characters to an Event

> As a user, I want to link one or more characters to an event, so that I can record who participates in the event and include it in each relevant character’s story journey.

#### US40 Record Character Roles in an Event

> As a user, I want to record each linked character’s role in an event, so that I can understand how each character participates in or is affected by the event.

#### US41 Link an Event to the Story Structure

> As a user, I want to link an event to a specific act, chapter or scene, so that I can see where the event appears in the planned manuscript.

#### US42 Record Character Appearances

> As a user, I want to associate a character with the chapters and scenes in which the character appears, so that I can review where the character is present throughout the manuscript.

#### US43 View Event Details and Connections

> As a user, I want to view an event’s details, participants and story connections in one place, so that I can understand the event without searching through multiple parts of the project.

#### US44 View All Events for a Character

> As a user, I want to view all events and milestones linked to a selected character in chronological order, so that I can review the character’s complete story journey.

#### US45 Edit an Event

> As a user, I want to edit an event’s details, participants and story connections, so that I can update the event when the plot or timeline changes.

#### US46 Delete an Event

> As a user, I want to delete an event I no longer need, so that obsolete event information does not remain in the timeline or other related parts of the project.

#### US47 Record Detailed Event Notes

> As a user, I want to add detailed notes to an event, so that I can develop its purpose, consequences and connection to the wider story beyond its basic information.

#### US48 Record Character Relationships

> As a user, I want to record relationships between characters and how those relationships change during the story, so that I can follow the development of character relationships over time.





### Epic 7: Timeline and Continuity

#### US49 View a Chronological Story Timeline

> As a user, I want to view dated story events and character milestones in chronological order on a unified timeline, so that I can understand the sequence in which events occur in the story world.

#### US50 Display Chapters and Scenes on the Timeline

> As a user, I want the timeline to show the story time associated with chapters and scenes, so that I can compare the chronological sequence of events with the order in which the manuscript presents them.

#### US51 Display Character Ages and Locations

> As a user, I want the timeline to display each linked character’s age and location at an event, so that I can check whether the character information remains consistent across the story.

#### US52 Control Timeline Information

> As a user, I want to control which information is displayed on the timeline, so that I can focus on the information relevant to my current planning task.
>
> I want to be able to:
>
> a) Filter events by character;
>
> b) Filter events by category;
>
> c) Filter the timeline by chapter or scene;
>
> d) Show or hide character, event and story-structure information.

#### US53 Open Related Content from the Timeline

> As a user, I want to select an item on the timeline and open its details or related story content, so that I can inspect or edit it without manually searching elsewhere.

#### US54 Reposition an Event on the Timeline

> As a user, I want to reposition an event on the timeline, so that I can adjust the chronological order of my story efficiently.

#### US55 Zoom the Timeline

> As a user, I want to zoom in and out of the timeline, so that I can examine a detailed period or view the chronology of the complete story.

#### US56 Undo a Timeline Change

> As a user, I want to undo my most recent timeline change, so that I can recover quickly from an accidental edit.

#### US57 Identify Possible Continuity Problems

> As a user, I want the system to identify possible age, date-order and location conflicts in the timeline, so that I can review and correct continuity problems before they appear in the manuscript.





### Epic 8: Saving, Data Safety and Cross-device Work

#### US58 Automatically Save Project Changes

> As a user, I want project changes to be saved automatically, so that I do not lose my planning work if I close the application or experience an interruption.

#### US59 Display the Save Status

> As a user, I want to see whether my latest project changes have been saved successfully, so that I know whether my work is safe.

#### US60 Warn About Unsaved Changes

> As a user, I want to be warned before leaving the application when some changes have not been saved, so that I have an opportunity to protect my work.

#### US61 Reopen a Saved Project

> As a user, I want to reopen a previously saved project with its planning information restored, so that I can continue working from where I stopped.

#### US62 Back Up and Restore a Project

> As a user, I want to create and use a complete project backup, so that I can recover my work or move it to another device.
>
> I want to be able to:
>
> a) Export the project as a backup file;
>
> b) Import a backup file to restore the project.

#### US63 Synchronise a Project Across Devices

> As a user, I want to access the latest version of the same project on my Windows and iOS or iPadOS devices, so that I can continue working across devices without manually transferring a backup file.





### Epic 9: Scrivener, Microsoft Word and Cross-platform Access

#### US64  Export to Scrivener

> As a user, I want to export my story plan in a format that Scrivener can import, so that I can transfer the planned manuscript structure and continue my writing workflow in Scrivener.

#### US65 Export to Microsoft Word

> As a user, I want to export my story plan as a document that Microsoft Word can open, so that I can review or continue developing my work in Word.

#### US66 Use the Application on Windows and iOS/iPadOS

> As a user, I want to access and edit my projects through supported web browsers on Windows and iOS or iPadOS devices, so that I can use the application without being limited to macOS.





### Epic 10: Profile, Preferences and Future Extensions

#### US67 Manage a User Profile

> As a user, I want to set and update my display name and profile image, so that I can personalise my identity within the application.

#### US68 Display the Active Project

> As a user, I want the application to display the name of the project I am currently editing, so that I can confirm that I am working on the correct writing project.

#### US69 Adjust Application Preferences

> As a user, I want to adjust preferences such as the default timeline view and date format, so that the application better matches my way of planning and viewing story information.

#### US70 Add a Project Image or Logo

> As a user, I want to assign a custom image, logo or book cover to a project, so that I can recognise the project visually in my project list.

#### US71 Receive Contextual Writing Tips

> As a user, I want to receive relevant writing and planning tips while working on my project, so that I can identify information that may help improve the consistency and quality of my story plan.

#### US72 Create an Author Wiki Page

> As a user, I want to create and publish an author wiki page, so that I can share organised information about myself and my books with readers.

#### US73 Publish Book Information for Readers

> As a user, I want to publish selected book information for readers without exposing my private planning data, so that readers can learn more about the book safely.
